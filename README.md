# Little Nest Baby Store

A responsive React + Vite starter e-commerce store for baby products, priced in South African rand.

## Current features
- Responsive storefront
- Product catalogue and categories
- Search
- Working cart with quantity controls
- ZAR price formatting
- South Africa-focused copy
- Starter checkout button ready for payment integration

## Run locally in VS Code
```bash
git clone https://github.com/siphosethuradebe8/Siphosethu.git
cd Siphosethu
npm install
npm run dev
```

Then open the local URL shown by Vite, normally `http://localhost:5173`.
